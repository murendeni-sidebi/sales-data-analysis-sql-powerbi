# Sales Data Analysis – SQL & Power BI

## Overview
This project analyses sales transactions using Microsoft SQL Server and Power BI.

## Key Results
- Total Sales: R2.47 million
- Total Profit: R500.8K
- Profit Margin: 20%
- Orders analysed: ~3,000

## What I did
- Designed and loaded a relational database (customers, products, orders)
- Wrote SQL queries using JOINs, GROUP BY and aggregate functions
- Built an interactive Power BI dashboard with KPIs, trends and slicers

## Files
- `Sales_Analysis_Queries.sql` – SQL queries used for analysis
- `Power BI project.pbix` – Interactive dashboard

# Sales Data Analysis – SQL & Power BI

## Overview
This is a self-taught project where I analysed sales transactions using Microsoft SQL Server and Power BI. The goal was to practise building a clean relational database, writing useful SQL queries, and presenting the results in an interactive dashboard.

## Key Results
- **Total Sales:** R2.47 million  
- **Total Profit:** R500.8K  
- **Profit Margin:** 20%  
- **Orders analysed:** ~3,000  

## What I did
- Designed and loaded a relational database with customers, products and orders tables
- Wrote SQL queries using JOINs, GROUP BY and aggregate functions to analyse performance by category, region and customer segment
- Built an interactive Power BI dashboard with KPI cards, sales trends and slicers
- Focused on clear structure, readable queries and results that are easy to review

## Files
- `Sales_Analysis_Queries.sql` – SQL queries used for the analysis  
- `Power BI project.pbix` – Interactive dashboard  

## Tools used
- Microsoft SQL Server Management Studio  
- Power BI Desktop
